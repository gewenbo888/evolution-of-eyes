# The Evolution of Eyes · 眼之演化

A systems-level platform on the evolution of vision — from the first light-sensitive pigment to the visual cortex, from trilobite calcite lenses to mantis-shrimp polarization, from cave painting to AI vision. Bilingual (EN / 中文), dark/light, cosmic-biological aesthetic with Aboreto + Lexend + Roboto Mono on deep ink with iris-amber, neural-violet, retina-cyan, leaf-green, and (sparingly) blood-red accents. Ten modules: a horizontally-scrolling 8-stage eye-evolution timeline (light-sensitive pigment → eyespot → cup → pinhole → lens → compound → camera eye → vision+cortex) with inline-SVG icons; physics-of-light module with electromagnetic spectrum bar (visible band marked) plus four cards (photons, spectrum-and-water selection, refraction, polarization); brain module with four cards (retinal pre-processing, V1 orientation columns, two-stream what/where, predictive-processing); predator-prey arms-race simulator (4 levers × 6 outcome dimensions); six-species comparison grid (human, octopus, dragonfly, trilobite, jumping spider, mantis shrimp) with inline-SVG eye icons and per-species stats; six-row colour-perception comparison table (dichromat → tetrachromat → mantis shrimp → pit viper → cuttlefish); four consciousness cards (blindsight, illusions, dreams, hard-problem-of-consciousness honesty); four visual-culture cards (cave paintings → perspective → photography → generative imagery); four AI-vision cards (hierarchical convergence, sample-efficiency divergence, adversarial failures, surveillance honesty); four future-of-seeing cards (retinal implants, AR, BMI, anti-utopian honest framing); AI Evolutionary Biologist with five canned multi-paragraph responses (incl. honest treatment of the contested Cambrian-light-switch hypothesis) and free-text heuristic fallback; explicit guardrails section refusing teleology, &quot;higher/lower species&quot; framings, design language for evolved structures, utopian transhumanism, and false closure on hard-problem-of-consciousness questions.

## Stack

Plain HTML, CSS, vanilla JavaScript. No build step. Bilingual via `[data-lang]` + CSS attribute selectors. Light/dark via `[data-theme]`. Aboreto display, Lexend body, Roboto Mono mono. All diagrams inline SVG. JS uses template literals throughout — verified with `node --check`.
